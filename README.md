# alzza-insta — 알짜야호 인스타 카드뉴스 자동 게시

'놓치면 손해 생활 알짜정보' 인스타그램 카드뉴스를 **정해 둔 시각에 인스타 공식 API로 올리는** 저장소예요.

## 어떻게 돌아가나요

1. **카드 만들기 (Claude)** — 일·수요일 아침 블로그 원고를 만들 때 글마다 카드(1080×1350, 4:5)를 만들어
   미리보기(insta.html)와 **깃허브 링크**를 보내요.
2. **대기열에 올리기 (야호님, 게시물마다 버튼 두 번)** — 카드를 확인하고 링크(또는 insta.html의 **깃허브 대기열에 올리기**)를 누르면
   이름·내용이 채워진 `queue/<게시일>/card.txt` 화면이 열려요 → **Commit changes...** → **Commit changes**.
3. **카드 그리기 (깃허브)** — 액션 **'인스타 카드 만들기'**가 card.txt로 같은 카드를 다시 그려
   `queue/<게시일>/`에 JPEG·caption.txt·post.json을 넣어요. (2~3분)
4. **게시 (깃허브)** — 액션 **'인스타 자동 게시'**가 매시 7분에 확인해서 게시 시각(기본 낮 12시)이 지난 게시물을
   하나씩 올리고, 폴더를 `posted/`로 옮겨요. 게시 주소는 `posted/<게시일>/result.json`에 남아요.
5. **토큰 연장 (깃허브)** — 액션 **'인스타 토큰 연장'**이 매주 월요일 토큰 기한을 다시 60일로 늘려요.

> Claude 예약 작업은 보안상 이 저장소에 직접 올릴 수 없어요. 그래서 카드 내용을 압축한 글자 파일(card.txt)을
> '새 파일 만들기' 링크에 담아 보내고, 그림은 깃허브가 같은 스크립트로 다시 그려요.

```
queue/2026-10-01/   card.txt  →(카드 만들기)→  01.jpg … 09.jpg · caption.txt · post.json
posted/2026-10-01/  (게시가 끝나면 이리로 옮겨져요) + result.json
kit/                insta_card_kit.py(카드 그리는 스크립트) · poses/(캐릭터 포즈 그림)
scripts/            render_queue.py(카드 만들기) · publish.py(게시) · refresh_token.py(토큰 연장)
.github/workflows/  render.yml · publish.yml · refresh-token.yml
```

## 처음 설정 (한 번)

1. **이 저장소에 파일 넣기** — `kit`, `scripts`, `README.md`는 업로드 화면에 끌어다 놓고,
   `.github/workflows/`의 세 파일은 **Add file → Create new file**로 만들어요(점으로 시작하는 폴더는 끌어다 놓기로 안 올라가요).
2. **인스타를 프로페셔널 계정으로 전환** — 인스타 앱 → 설정 → 계정 유형 및 도구 → 프로페셔널 계정(크리에이터).
3. **Meta 개발자 앱과 토큰 만들기** (본인 계정에만 쓰면 앱 심사는 필요 없어요)
   - developers.facebook.com 에 **페이스북 계정으로** 로그인 → 개발자 등록(휴대폰·이메일 인증).
     개발자 등록은 개인 페이스북으로 해도 인스타 계정에는 드러나지 않아요.
   - **앱 만들기** → 비즈니스 유형 → 제품에서 **Instagram** 추가 → **Instagram 로그인을 통한 API 설정**.
   - **앱 역할 → 역할 → Instagram 테스터**에 인스타 아이디를 추가하고, 인스타(웹: 설정 → 앱 및 웹사이트 → 테스터 초대)에서 수락.
   - **액세스 토큰 생성 → 계정 추가 → 토큰 생성**. 권한에 `instagram_business_basic`, `instagram_business_content_publish`가 있어야 해요.
4. **토큰을 저장소 비밀값에 넣기** — 이 저장소 **Settings → Secrets and variables → Actions → New repository secret**
   - `IG_ACCESS_TOKEN` : 방금 만든 토큰 (필수)
   - `GH_PAT` : (선택) 토큰이 새로 발급됐을 때 자동으로 바꿔 넣으려면, 이 저장소의 *Secrets* 쓰기 권한만 준 fine-grained 토큰
5. **확인** — **Actions → 인스타 자동 게시 → Run workflow → `check`** 가 초록색이면 준비 끝이에요.
   `dry-run`은 올릴 게시물과 이미지 주소만 확인하고 게시는 하지 않아요.

## 게시 멈추기 · 시각 바꾸기

- **멈추기**: `queue/<게시일>/post.json`을 열고 연필(✏️) 버튼 → `"hold": false`를 `true`로 → **Commit changes**.
  아직 안 올린 게시물이면 그 날짜 폴더를 올리지 않으면 돼요.
- **다시 올리기**: `hold`를 `false`로 바꾸면 다음 확인 때 올라가요.
- **시각 바꾸기**: `publish_at`을 고쳐요. 예: `2026-10-01T19:00:00+09:00`

## 안전장치

- **같은 게시물 두 번 올리기 방지** — `posted/`에 같은 날짜 폴더가 있으면 다시 올려 둬도 게시하지 않고 대기열에서 빼요.
  일부러 한 번 더 올리려면 `post.json`에 `"repost": true`를 넣어요.
- **철 지난 게시물 방지** — 예정 시각보다 18시간 넘게 늦게 올라온 게시물은 올리지 않고 자동 보류해요(알림 메일이 가요).
  그래도 올리려면 `publish_at`을 새로 정하고 `hold`를 `false`로 바꿔요.
- **한 번에 하나씩** — 밀린 게시물이 여러 개면 한 시간에 하나씩 올려요.
- **카드를 못 만들면** — card.txt를 `card_실패.txt`로 바꿔 두고 메일로 알려요. Claude가 보낸 링크를 다시 누르면 새로 올라가요.
- **직접 올리기도 돼요** — JPEG·caption.txt·post.json이 든 날짜 폴더를 `queue/`에 올려도 같은 규칙으로 게시돼요.
- **실패하면** 깃허브가 메일로 알려 줘요. 이유는 `post.json`의 `last_error`와 Actions 실행 기록에 있어요.
  같은 게시물이 3번 실패하면 자동으로 보류돼요. 원인을 고친 뒤 `hold`를 `false`로 바꾸면 다시 올려요.
- 토큰이 만료됐다면 Meta 개발자 페이지에서 토큰을 다시 만들어 `IG_ACCESS_TOKEN`을 바꿔요.

## 알아둘 점

- **공개 저장소예요.** 인스타가 이미지 주소에서 카드를 직접 가져가는 방식이라 공개여야 해요. 토큰·비밀번호·개인정보는 파일에 쓰지 말고 **비밀값에만** 넣어요.
- **공식 API만 써요.** 로그인 매크로 같은 비공식 자동화는 계정 정지 위험이 있어 쓰지 않아요.
- 인스타 API는 **JPEG · 4:5~1.91:1 비율 · 캐러셀 10장까지**만 받아요.
- `kit/insta_card_kit.py`는 Claude가 쓰는 스크립트와 같은 버전이어야 카드가 똑같이 그려져요. 다르면 '카드 만들기' 요약에 경고가 떠요.
- 깃허브 예약 실행은 붐빌 때 몇십 분 늦을 수 있어요. 하루 1편이라 문제없어요.
- 공개 저장소에서 60일 동안 아무 변화가 없으면 깃허브가 예약 실행을 멈춰요. 매일 게시 기록이 남아서 괜찮아요.
